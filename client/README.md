# Job Portal Client

React/TypeScript and Vite frontend for the public job-portal repository. The client contains page, route, and API configuration for marketplace workflows.

From `client/`, run `npm install` and `npm run dev`. `npm run build`, `npm run lint`, and `npm run preview` are also available. Configure the API URL in the client source to match the server. See the repository-level [`README`](../README.md), including its data-handling note, before running or sharing the project.
